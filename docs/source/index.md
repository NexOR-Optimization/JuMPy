# JuMPy documentation

JuMPy is a Python interface to [JuMP](https://github.com/jump-dev/JuMP.jl) and
[GenOpt](https://github.com/blegat/GenOpt.jl), with native
[MathOptInterface](https://github.com/jump-dev/MathOptInterface.jl) sets. Python
operators construct native Julia expressions; GenOpt expands compact model
templates in the Julia backend.
